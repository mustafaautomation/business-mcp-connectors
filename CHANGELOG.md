# Changelog

## 0.1.0

- HubSpot, ClickUp, Google Sheets, and Notion MCP servers with sandbox fixtures and live API adapters.
- Shared core for mode, the read-only switch, retries, pagination, and redacted stderr logs.
- Won-deal workflow: HubSpot `closedwon` to ClickUp onboarding tasks, a Sheets row, and a note.
- Public read-only sandbox over stateless Streamable HTTP at `/mcp`, plus `/api/sandbox` for the landing page.
- Vitest coverage, GitHub Actions, client config snippets, and the portfolio site.
